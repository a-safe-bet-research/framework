2. Where a deposit file exists as both `.docx` and `.pdf`, both are carried under the same appendix number.
3. `asb_framework_tables.docx` is byte-identical to `ASB_TranslatingEvidence_Revision1_Tables_Clean.docx` in the resubmission final set (`Submission_Package/Revision/06_Coauthor_Package/ASB_TranslatingEvidence_Revision1_FINAL_FOR_UPLOAD/`, 28 September 2026). The resubmission set contains no PDF of the tables, so `asb_framework_tables.pdf` is a local export from that docx, made 28 September 2026; no journal-typeset tables PDF exists.
4. Repository copies of the deposit files were placed on 15 September 2026 (record 411 corrections and codebook revision 1.1) and 28 September 2026 (codebook revision 1.2 and the corrections to 02.2, 02.3, 02.4, 02.5, 03.3, 04.1, 04.3, 05.2, 05.3 and 05.4), then refreshed from the 29 September 2026 deposit and verified byte-identical (see `github/notes/framework_refresh_notes.md`). Twenty files differ from the first upload set of 10 September 2026; twelve are unchanged since then.
5. The Version note column records revisions made to a file after the first upload of the materials to the repository (10 September 2026). "None recorded" means no revision has been recorded for that file in this map, and the file is byte-identical to the 10 September copy. Change descriptions come from the codebook revision histories where a file has one (04.2, section 5.5), otherwise from the repository change log.
6. The OSF deposit keeps the manuscript's cited names. The corrected taxonomy dataset is deposited on OSF as `03_1_Taxonomy_Dataset_v2.xlsx` beside the superseded `03_1_Taxonomy_Dataset.xlsx`, which is not carried in the repository; the repository file `asb_framework_03_1_taxonomy_dataset.xlsx` is the current version and carries no version suffix (git is the version).
