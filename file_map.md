Source files for the files revised in peer review are the current versions in `Paper_1_RGF/OSF/`: Appendices 02.4 and 03.3 (docx 14 September 2026, PDFs regenerated 15 September 2026), the taxonomy dataset (`03_1_Taxonomy_Dataset_v2.xlsx`, 14 September 2026) and Appendix 04.2 (codebook revision 1.1, 3 September 2026). Placed in the repository on 15 September 2026 (Brief G).
5. The Version note column records revisions made to a file after the first upload of the materials to the repository (the upload set built on 10 September 2026). "None recorded" means no revision has been recorded for that file in this map; it does not assert that the file is identical to the OSF deposit at submission.
